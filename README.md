# تریدر شو (Trader Show)

پروژه‌ی Android Studio (Kotlin + Jetpack Compose) برای بازی شبیه‌سازی ترید «تریدر شو».

## نحوه‌ی باز کردن پروژه

1. Android Studio (نسخه‌ی Koala/2024.1 یا جدیدتر پیشنهاد می‌شود) را باز کنید.
2. `Open` را بزنید و پوشه‌ی `TraderShow` را انتخاب کنید.
3. صبر کنید تا Gradle Sync کامل بشه (نیاز به اینترنت داره چون Compose، کتابخونه‌ی مایکت، و SDK ادیوری باید دانلود بشن).
4. روی دستگاه/شبیه‌ساز Run بگیرید.

## چی پیاده‌سازی شده (نسخه‌ی اول)

- ثبت‌نام (نام و نام خانوادگی) + ذخیره‌ی پروفایل محلی
- ۱۶ ارز قابل معامله (کریپتو، فارکس، کالا، ۴ ارز ساختگی داخل بازی) با موتور شبیه‌سازی قیمت seed-based و deterministic
- چارت کندل‌استیک با Canvas سفارشی Compose (بدون کتابخونه‌ی خارجی)
- باز/بستن پوزیشن Long/Short با سود و زیان لحظه‌ای
- کیف پول دوارزی (دلار/تومان) با نرخ تبدیل ثابت ۱$=۲۲۰,۰۰۰ تومان و تبدیل دستی توسط کاربر
- بک‌فیل آفلاین: هنگام باز شدن مجدد اپ، قیمت‌ها بر اساس زمان واقعی سپری‌شده به‌روزرسانی می‌شن (کندل‌های دقیقه‌ای برای ۲۴ ساعت اخیر، ساعتی برای قدیمی‌تر)
- شارژ حساب: تبلیغ جایزه‌ای ادیوری (سقف ۶ بار/روز، فاصله ۲ دقیقه) + سه بسته‌ی خرید درون‌برنامه‌ای مایکت (مصرف‌شدنی)
- بخش «زندگی من»: نوار سلامتی/گرسنگی/انرژی + چند آیتم قابل خرید با تومان
- بخش «درباره ما» (متن پیش‌فرض، قابل ویرایش)

## چیزهایی که هنوز کامل نیست / باید با هم ادامه بدیم

- **چالش‌های روزانه** هنوز به UI وصل نشدن (منطق طراحی‌شده بود، پیاده‌سازی صفحه‌ش باقی مونده)
- **آیکون برنامه**: یک آیکون placeholder ساده گذاشته شده (فلش سبز)؛ وقتی آیکون نهایی (.png) رو ساختی، فایل‌های `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` و `drawable/ic_launcher_foreground.xml` رو با آیکون خودت جایگزین کن (یا از Image Asset Studio داخل Android Studio استفاده کن: راست‌کلیک روی res > New > Image Asset)
- **سیستم لول/XP**: ساختارش گذاشته شده ولی منطق افزایش لول بر اساس خرید در «زندگی من» هنوز وصل نشده
- **کلید Keystore انتشار**: برای انتشار نهایی در مایکت باید خودتون یک keystore واقعی بسازید و signingConfig مربوط به release رو در `app/build.gradle` تنظیم کنید (فعلاً release بدون امضای اختصاصی تعریف شده)

## یک نکته‌ی مهم فنی (نیاز به تأیید تو موقع Sync)

کتابخونه‌ی `com.github.myketstore:myket-billing-client:1.6` طبق مستندات مایکت استفاده شده، اما مستندات نام دقیق **پکیج Kotlin/Java** کلاس‌های `IabHelper`، `IabResult`، `Inventory`، `Purchase` رو ننوشته بود. توی `BillingManager.kt` فعلاً حدس زدم `ir.market.billingclient` — بعد از Sync کردن پروژه در Android Studio، اگه این import قرمز/خطا بود:
1. روی نام کلاس `IabHelper` که import اشتباهه کلیک کن
2. `Alt+Enter` بزن و از پیشنهادهای Android Studio پکیج درست رو انتخاب کن (یا داخل کتابخونه که در Gradle دانلود شده جستجو کن)
3. همون اصلاح رو برای بقیه‌ی import های همون فایل انجام بده

بقیه‌ی منطق (نحوه‌ی صدا زدن متدها، ترتیب پارامترها) دقیقاً طبق مستندات رسمی مایکته و نیازی به تغییر نداره.
